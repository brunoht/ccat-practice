Tips:

Remember: Order is king

- Synonym | Antonym -> 
- Individual | Group -> Singer:Chorus::Soldier:Platoon
- Classification | Type -> Guitar:Instrument::Shirt:Clothing
- Characteristic -> Hair:Bald::Courage:Coward
- Part | Hole -> Blade:Fan::Lens:Camera
- Source-Product-Production (a product made made out or made by the other word) -> Blacksmith:Steel::Carpenter:Wood
- Tool | Function -> Scissors:Cut::Needle:Knit
- Sequence | Process (sequential steps in a larger process) -> 
    Infant:Toddler::Teen:Adult
    Caterpillar:Butterfly :: Tedpole:Frog
- Family relationships/Taxonomy (will be related in a familial way) -> 
    Cow:Calf(baby cow) :: Horse:Foal (baby horse)
    Grandfather:Grandson :: Granmother:Granddaugther
