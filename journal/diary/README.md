# Diary

Objective project/study progress for CCAT prep. Written from `session-buffer.md` on request — not every chat turn. Complements `journal/reflections/` (subjective perceptions). On consolidation, agents may add a short Self-management line from that day’s reflection file.

**Convention:** one file per day — `YYYY-MM-DD.md`. Each file has a short summary at the top; on consolidation, that day’s `session-buffer.md` entries are moved unchanged to the end of the same day file. Persisted in English; chat may stay in Portuguese.
