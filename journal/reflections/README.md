# Reflections

Personal perceptions and feelings during CCAT prep. Complements `journal/diary/` (objective project/study progress, one file per day) — this folder is subjective: energy, confidence, doubt, load, what felt heavy or useful. On diary consolidation, agents may synthesize a short Self-management line from that day’s reflection; keep the full perception detail here.

**Convention:** one file per day — `YYYY-MM-DD.md`. Persisted in English; chat may stay in Portuguese.
